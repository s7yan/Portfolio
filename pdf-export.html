Hero

Launchpad — The Hero

Layout Skeleton
┌─────────────────────────────────────────────────┐ │ [Top Nav] fixed │ │ │ │ Designing at the speed of ← 18vh top │ │ thought. 64px serif │ │ │ │ [3D Circuit Cube] ← center │ │ [Mountains · Water] WebGL │ │ │ │ AI-First Product Designer... ← auto ~73vh │ │ [body text, 20px C&L Bold] │ │ │ │ ✦ EXPLORE MY WORK [cta button] ← below body │ │ │ │ [Bottom Bar] fixed │ └─────────────────────────────────────────────────┘
Headline — Libre Baskerville, 64px, weight 400, white
"Designing at the speed of thought."
"thought." → Libre Baskerville Italic · color #00ccff · Animation: translateY(105%) → 0, 1.3s, power4.out
Body Text — Champagne & Limousines Bold, 20px, color #5a6e8e
"AI-First Product Designer with a postgraduate specialization in Interaction Design, building scalable digital experiences across SaaS, enterprise, automotive, and AI-driven platforms through rapid execution, product thinking, motion-led interactions, and intuitive system design."
CTA Button — Space Grotesk, 0.7rem uppercase, bordered
"✦ Explore My Work" → links to #work · Hover: blue glow border
3D Scene — WebGL / Three.js
Central Object: BoxGeometry cube, size 3.5, rotated (0.35, 0.75, 0.1). 6 faces each with unique procedural PCB circuit board texture — Canvas2D generated: glowing cyan traces (rgba 0,200,255,0.9), IC chip outlines, solder pads, via holes, dark navy base (#030810).

Environment: Dark neon blue mountains (5 ranges), reflective water plane, 3000 ambient particles + 500 near-cube particles, sky gradient background.

Camera: 11-keyframe scroll-driven path with smoothstep interpolation. Mouse parallax offset (±0.6x, ±0.3y). Hero position: Vector3(0, 5, 22) → lookAt(0, 4.5, 0).
